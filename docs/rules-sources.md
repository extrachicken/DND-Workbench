# Реестр источников D&D 2014

Снимок `2026-11-23.2` для Workbench 0.8.2. Ссылки и видимые версии сверены
23 ноября 2026 года. Снимок охватывает основные книги, источники расчётов
Workbench и публикации, использованные в описи классов 5e14.
[Опись классов и вложенных опций](class-options.md).

В следующем снимке сохраняйте ID прежних записей, указывайте версии и дату
сверки. Для вложенной игровой опции фиксируйте раздел и её собственный
источник. Условия включения текста и состояние механики указывайте отдельно.
