# Состояние разработки — 14 ноября 2026

## Завершено

- Инженерный план и проверочный кейс Гу Ченя.
- Дизайн-система и интерактивный прототип 0.1.
- React/TypeScript/Vite, IndexedDB, проверяемая схема резервной копии.
- Ресурсы учебного листа, кубики, простой инвентарь, история и портрет, журнал, черновик создания.

- Браузер: desktop 1280 px, mobile 393 px без горизонтального переполнения; урон и нулевой остаток ячеек переживают перезагрузку; сохранены черновик и заметка; после обновления данные сохранены; production-страница загружается при эмуляции отсутствия сети, журнал доступен.

## Открытые технические ограничения

- Audit инструментов сборки: 6 записей low/moderate в цепочке Workbox. Production-зависимости: 0 на дату проверки. Перед публикацией устранить/оценить оставшиеся записи; не применять major overrides вслепую.
- Нет автоматизации отдыха, концентрации, состояний, смерти, атак, снаряжения, повышения уровня и большей части классов.
- Нет сервера, синхронизации, размещения на HTTPS, APK, публичного каталога или внешних отправок данных.
- Текст заметки и истории пишется автоматически; названия заметки и кампании — при выходе из поля. Создание пока сохраняет только имя/происхождение/класс, не полноценного игрового персонажа.
- Переключение единиц затрагивает демонстрационную скорость. Полная система мер и веса — впереди.

## Продолжение после остановки

Прочитать README.md, docs/design.md, этот файл и релевантную часть engineering-plan.md. Выполнить npm ci, npm test, npm run build. Предпросмотр: npm run preview -- --port 4173. Данные браузера привязаны к origin; не менять порт, если нужно видеть ту же учебную копию.

Сброс недельного лимита не является функцией проекта и не настроен. Прогресс сохранён в локальных файлах для продолжения.
