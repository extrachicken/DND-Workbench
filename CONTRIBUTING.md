# Работа над DND Workbench

Проект развивается для личного использования. Основной язык интерфейса,
обсуждений и документации — русский. Используем правила 2014; материалы 2024
не подключаем неявно.

## Локальная разработка

1. Установите Node.js 24 (версия указана в `.node-version`).
2. Выполните `npm ci`.
3. Запустите `npm run dev`.
4. Перед коммитом выполните `npm run format` и `npm run check`.

Для проверки service worker используйте `npm run build`, затем
`npm run preview -- --port 4173`. Порт входит в адрес хранилища: смена порта
создаёт отдельное пространство данных.

## Изменения

- Для законченной задачи создавайте небольшую ветку и PR с описанием результата.
- Проверяйте настоящие границы поведения: расход ресурсов, независимость
  персонажей, перенос данных, ошибочный импорт. Не подменяйте их тестами разметки.
- Изменение схемы IndexedDB сопровождайте миграцией и тестом обновления старой БД.
- Не восстанавливайте потраченные ресурсы при пересчёте, открытии или импорте листа.
- Новые механики должны содержать источник, версию и тесты. Наличие класса
  в списке выбора не означает, что его механики автоматизированы.
- Проверяйте изменения интерфейса на узком экране и с клавиатуры.
- Обновляйте `docs/progress.md`, если завершён очередной этап.

Не коммитьте `.env`, токены, выгрузки хранилища, чужие PDF и личные портреты.
Снимки экрана должны содержать учебные данные. Правила работы с содержимым
описаны в [docs/content-policy.md](docs/content-policy.md).
